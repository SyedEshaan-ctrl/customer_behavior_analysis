👨🏻‍💻 Customer Behavior Data Analyst Portfolio Project

An end-to-end data analytics project covering the full workflow an analyst actually uses on the job — from raw data to a business-ready dashboard. This project spans data preparation, SQL-based analysis, Power BI visualization, and insight reporting on a customer shopping/purchase behavior dataset.

This project was built by implementing and independently reproducing a public tutorial, then extending the analysis with my own queries, dashboard design choices, and findings.

📌 Project Overview

The goal: simulate a real, corporate-grade analytics workflow — translating raw customer data into strategic business insight — covering:

✅ Data Preparation, Modeling & EDA (Python) — cleaned and transformed the raw dataset for analysis
✅ Data Analysis (SQL) — simulated business transactions and ran queries to extract insights on customer segments, loyalty, and purchase drivers
✅ Visualization & Insights (Power BI) — built an interactive dashboard highlighting key patterns and trends for stakeholder decision-making
✅ Reporting — summarized key findings and business recommendations in a clear project report
🛠 Tech Stack

Python (Pandas) · SQL (PostgreSQL/MySQL) · Power BI · Jupyter Notebook

🚀 Project Workflow

1. Data Preparation & EDA (Python)

Imported and explored the raw customer shopping dataset
Cleaned inconsistencies, handled missing values, transformed fields for downstream analysis

2. Data Analysis (SQL)

Loaded cleaned data into a SQL database
Wrote business-focused queries to answer questions on customer segments, purchase drivers, and loyalty patterns — e.g., which segments drive repeat purchases, what factors correlate with higher spend, how purchase behavior differs across customer groups

3. Visualization (Power BI)

Connected the SQL database to Power BI
Built an interactive dashboard surfacing key trends — customer segmentation, purchase patterns, and loyalty indicators — designed for a non-technical stakeholder audience

4. Reporting

Summarized findings and business recommendations in a project report, translating the analysis into actionable next steps

## ▶️ Getting Started

**Repository:** [customer_behavior_analysis](https://github.com/SyedEshaan-ctrl/customer_behavior_analysis)

```bash
git clone https://github.com/SyedEshaan-ctrl/customer_behavior_analysis.git
cd customer_behavior_analysis
```

Open Customer_Shopping_Behavior_Analysis.ipynb and run the data import, exploration, and cleaning steps.

Load the cleaned data into a SQL database (PostgreSQL/MySQL).

Open customer_behavior_sql_queries.sql and run the queries to answer the business questions.

Open customer_behavior_dashboard.pbix in Power BI to explore the interactive dashboard.
